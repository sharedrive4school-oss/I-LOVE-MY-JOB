# ระบบตารางสอนของโรงเรียนวัดแสนเกษม — Phase 2–12

ชุดนี้ครอบคลุม Phase 2–4 (ฐานข้อมูล แผ่นงานพร้อมข้อมูลจริง Backend), Phase 5 (จัดตารางประจำสัปดาห์อัตโนมัติ), Phase 6 (ตรวจความขัดแย้ง + แก้ตารางด้วยการสลับคาบ), Phase 7 (ตารางรายวันตามวันที่จริง), Phase 8 (ครูไม่อยู่), Phase 9 (จัดสอนแทน) และ Phase 10–12 (หน้าเว็บสำหรับครูและ Admin รองรับมือถือ พิมพ์/PDF)

**วิธีติดตั้งที่ง่ายที่สุด:** ใช้ 2 ไฟล์ในโฟลเดอร์ `dist/` — วาง `dist/Code.gs` ในไฟล์ Code.gs และ `dist/Index.html` ในไฟล์ HTML ชื่อ Index (ดูคู่มือทีละขั้นตอนที่ส่งแยก) ไฟล์อื่นในโฟลเดอร์นี้คือต้นฉบับแยกส่วนสำหรับผู้พัฒนา หน้าเว็บเต็มรูปแบบจะทำใน Phase 10

## วิธีติดตั้ง (ประมาณ 10 นาที)

1. เข้า Google Drive ด้วยบัญชีของโรงเรียน แล้วสร้าง Google Sheets ใหม่ ตั้งชื่อ เช่น `ระบบตารางสอน วัดแสนเกษม` (ไฟล์นี้คือฐานข้อมูล **อย่าแชร์ให้ครูทั่วไป** แชร์เฉพาะ Admin)
2. ในไฟล์ Sheets เลือกเมนู **ส่วนขยาย → Apps Script**
3. ในหน้า Apps Script:
   - คลิก ⚙️ **การตั้งค่าโปรเจกต์** → ติ๊ก **"แสดงไฟล์ Manifest 'appsscript.json' ในเครื่องมือแก้ไข"** แล้วแทนเนื้อหาไฟล์ด้วย `appsscript.json` ชุดนี้
   - ลบโค้ดเดิมใน `Code.gs` แล้ววางเนื้อหา `Code.gs` ชุดนี้
   - กด **+ → สคริปต์** เพื่อสร้างไฟล์ทีละไฟล์ ตั้งชื่อให้ตรง (ไม่ต้องพิมพ์ .gs): `Config`, `SeedData`, `Rules`, `Scheduler`, `Validation`, `Database`, `Auth`, `Admin`, `Master`, `Daily`, `Absence`, `Substitute`, `Views`, `Setup`, `Backup`, `Tests` แล้ววางเนื้อหาให้ตรงไฟล์
   - ถ้าติดตั้งชุดก่อนหน้าไปแล้ว: วางทับทุกไฟล์ที่มีอยู่ด้วยฉบับนี้ และเพิ่มไฟล์ที่ยังไม่มี (`Scheduler`, `Validation`, `Master`, `Daily`, `Absence`, `Substitute`, `Views`) — ข้อมูลใน Sheets ไม่ต้องทำใหม่
   - กด **+ → HTML** สร้างไฟล์ `Status` แล้ววางเนื้อหา `Status.html`
   - กด 💾 บันทึก
4. กลับไปที่ Google Sheets แล้วรีเฟรชหน้า จะมีเมนู **ระบบตารางสอน** เพิ่มขึ้นมา
5. เลือก **ระบบตารางสอน → 1) ตั้งค่าครั้งแรก**
   - ครั้งแรก Google จะขอสิทธิ์ ให้กด อนุญาต (ถ้าขึ้นว่า "Google ยังไม่ได้ยืนยันแอปนี้" กด ขั้นสูง → ไปที่โปรเจกต์)
   - ระบบจะสร้าง 17 แผ่นงานและนำเข้าข้อมูลครู 16 คน วิชา 23 รายการ และโครงสร้างคาบ 2/2569 ที่ครบทุกชั้น
6. เลือก **2) เพิ่ม/เปลี่ยนรหัสผ่าน Admin** เพื่อสร้างบัญชี Admin (รหัสผ่านอย่างน้อย 8 ตัว) — เพิ่มได้หลายคน
7. Deploy เป็น Web App: ในหน้า Apps Script กด **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → ประเภท: เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
   - กดทำให้ใช้งานได้ แล้วคัดลอก URL ไว้ (หน้าตอนนี้เป็นหน้าตรวจสถานะ — หน้าตารางจริงมาใน Phase 10)

## วิธีทดสอบ

**ใน Google Sheets:** เมนู **ระบบตารางสอน → ทดสอบระบบ** ต้องได้ "ผ่าน 44/44" (ใช้เวลาประมาณ 3–6 นาทีเพราะสร้างสำเนาไฟล์เพื่อทดสอบ)

- ส่วน A ตรวจไฟล์จริงแบบอ่านอย่างเดียว เช่น ทุกชั้นครบ 30 คาบ, DARE ไม่อยู่ภาคเรียน 2, ชุมนุมอังคารคาบ 6, ลูกเสือพฤหัสบดีคาบ 6
- ส่วน B ทดสอบการเขียนบน **สำเนาชั่วคราว** ของไฟล์ แล้วลบสำเนาทิ้ง เช่น เพิ่มครู เพิ่มวิชา ข้อมูลผิดถูกปฏิเสธ ภาคเรียนที่สิ้นสุดแก้ไม่ได้ และสร้างภาคเรียนใหม่โดยภาคเดิมไม่เปลี่ยน
- ส่วน D (Phase 5) บนสำเนาอีกชุด: จัดตารางได้และไม่สุ่ม, ครูชน/ชั้นชน/ครูประกบชนถูกปฏิเสธไม่ให้บันทึก, ฉบับร่างครูยังไม่เห็น, เผยแพร่แล้วดูตามวันที่ได้, แก้โครงสร้างหลังเผยแพร่ → "ต้องตรวจสอบใหม่"
- ส่วน E (Phase 6–7) บนสำเนาอีกชุด: สลับคาบที่อนุญาตบันทึกได้/ที่ทำให้ชนถูกปฏิเสธ, ตารางรายวัน 18 พ.ย. 2569, ยกเลิกคาบเฉพาะวันโดย Master ไม่เปลี่ยน, ครูอบรมถูกจัดสอนไม่ได้
- ส่วน F (Phase 8–9) บนสำเนาอีกชุด: ครูลา → รอจัดสอนแทน, บันทึกซ้อนไม่ได้, เสนอ-ยืนยันผู้สอนแทน, เลือกครูไม่ว่างไม่ได้, ลาหลายวันข้ามเสาร์-อาทิตย์, หมายเหตุการลาไม่แสดงต่อสาธารณะ, รายงานภาระ, ยกเลิกการลาแล้วการสอนแทนถูกยกเลิก
- ส่วน C ทดสอบ Login: token ปลอมถูกปฏิเสธ รหัสผิดถูกปฏิเสธ และข้อมูลสาธารณะไม่มีรหัสผ่าน

**ตรวจข้อมูลก่อนจัดตาราง:** เมนู **ตรวจข้อมูลก่อนจัดตาราง** จะแสดงยอดคาบรายชั้นและปัญหาที่พบ และบันทึกผลลงแผ่น "ตรวจสอบระบบ" ข้อมูลตอนนี้ไม่มีข้อผิดพลาด มีคำเตือน 3 รายการ:
- Teacher, ครูจีน และพระธนพล ใช้ช่องเวลาที่กำหนดเต็มทุกช่อง ถ้าวันนั้นเป็นวันหยุด คาบในสัปดาห์นั้นจะหายไป

**ในเครื่อง (สำหรับผู้พัฒนา):** `node tests/run-tests.js` รันโค้ดจริงบน Apps Script จำลอง — ผล ณ วันที่ส่งมอบ: ผ่าน 93/93 · หน้าเว็บทดสอบบน Chromium ทั้งจอคอมพิวเตอร์ (1280 px) และมือถือ (390 px) ไม่มี error และไม่มีการเลื่อนแนวนอนบนมือถือ

## การจัดตาราง (Phase 5)

ใช้จากเมนู **ระบบตารางสอน** (ระหว่างที่ยังไม่มีหน้าเว็บ Admin):

1. **จัดตารางอัตโนมัติ (บันทึกเป็นฉบับร่าง)** — ระบบตรวจข้อมูลก่อน (ถ้าไม่ผ่านจะไม่จัด) แล้วจัดและตรวจผลอีกครั้งก่อนบันทึก ดูผลได้ที่แผ่น "ตารางรายชั้น" และ "ตารางครู" — ครูทั่วไปยังไม่เห็นฉบับร่าง
2. **ตรวจสอบตารางทั้งหมด** — แสดง "✅ ไม่พบความขัดแย้ง สามารถเผยแพร่ตารางได้" หรือ "❌ พบความขัดแย้ง" พร้อมรายการ และบันทึกผลลงแผ่น "ตรวจสอบระบบ"
3. **เผยแพร่ตาราง** — ตรวจซ้ำกับข้อมูลล่าสุดอีกครั้ง ถ้ามีความขัดแย้งจะไม่เผยแพร่ ฉบับที่เผยแพร่ก่อนหน้าถูกเก็บถาวรพร้อมวันที่เริ่มใช้ จึงดูย้อนหลังได้ว่าวันใดใช้ฉบับไหน

กฎที่ตัวจัดตารางใช้:

- **กฎบังคับ (ห้ามฝ่าฝืน):** กิจกรรมล็อกเวลา, ครูประกบต้องว่างพร้อมกัน, เวลาไม่ว่างของครู, ครูไม่สอน 2 ห้องพร้อมกัน, ชั้นไม่เรียน 2 วิชาพร้อมกัน, จำนวนคาบตรงโครงสร้าง, วัน/คาบที่กำหนดของแต่ละวิชา
- **กฎพึงประสงค์:** วิชาเดียวกันไม่เกิน 1 คาบ/วัน (ถ้าจัดไม่ได้จะผ่อนเป็น 2 และแจ้ง), วิชาหลักอยู่คาบ 1–3 ให้มากที่สุด, ภาระครูต่อวันไม่เกิน 5 คาบ
- ถ้าจัดไม่ได้ ระบบหยุดและบอกวิชาที่จัดยากที่สุด — ไม่เปลี่ยนจำนวนคาบ ครู หรือวิชาเอง

ผลกับข้อมูลปัจจุบัน: จัดได้ครบ 180 คาบ ไม่มีความขัดแย้ง วิชาเดียวกันไม่ซ้ำวัน วิชาหลักอยู่ช่วงบ่าย ป.1: 1, ป.2: 1, ป.3: 2, ป.4: 2, ป.5: 3, ป.6: 2 คาบ (ป.1–ป.3 มีวิชาหลักมากกว่าช่องช่วงเช้า จึงหลีกเลี่ยงไม่ได้บางส่วน)

**แก้ตารางด้วยมือ (Phase 6):** สลับคาบสองคาบในชั้นเดียวกันของฉบับร่าง ระบบบอกล่วงหน้าว่าช่องไหนสลับได้ และช่องไหนสลับไม่ได้เพราะอะไร (`admin.swapOptions`) แล้วบันทึกเป็นฉบับร่างใหม่หลังตรวจผ่านเท่านั้น (`admin.editDraft`) — กิจกรรมล็อกเวลาย้ายไม่ได้ ปุ่มในหน้าเว็บจะมาใน Phase 10

## ตารางรายวัน (Phase 7)

- เมนู **ดูตารางรายวัน (เลือกวันที่)** → พิมพ์วันที่ เช่น `2026-11-18` → ระบบสร้างแผ่น "มุมมองตารางรายวัน" แสดงวัน ภาคเรียน สถานะวัน ครูที่ไม่อยู่ และตารางทุกชั้นพร้อมสถานะของแต่ละคาบ
- ตารางรายวันใช้ **ฉบับที่เผยแพร่ซึ่งมีผลในวันนั้น** แล้วซ้อนการเปลี่ยนแปลงเฉพาะวัน — ไม่แก้ตาราง Master
- สถานะคาบ: ปกติ · สอนแทน · รอจัดสอนแทน (ครูไม่อยู่และยังไม่มีผู้สอนแทน) · ยกเลิก · กิจกรรมพิเศษ · เปลี่ยนแปลง
- วันเสาร์–อาทิตย์ วันที่อยู่นอกภาคเรียน และวันที่ใส่ในแผ่น "ปฏิทินโรงเรียน" ว่าไม่มีการเรียนการสอน จะไม่มีตาราง
- การเปลี่ยนแปลงเฉพาะวัน (ยกเลิกคาบ / กิจกรรมพิเศษ / สลับคาบ) บันทึกผ่าน `admin.dailyChange` ซึ่งตรวจก่อนทุกครั้ง: ครูชน ครูที่ลาหรืออบรมถูกจัดสอน และครูในช่วงไม่ว่างประจำ จะถูกปฏิเสธ

## ครูไม่อยู่และการจัดสอนแทน (Phase 8–9)

**บันทึกครูไม่อยู่** (`admin.saveAbsence`): วันที่ (หรือช่วงวันที่), ครู, ประเภท (ลาป่วย ลากิจ ลาพักผ่อน อบรม ไปราชการ ติดภารกิจ อื่น ๆ), ทั้งวันหรือคาบเริ่ม–สิ้นสุด, หมายเหตุ
- ลาหลายวัน: บันทึกเฉพาะวันเรียน ข้ามเสาร์-อาทิตย์และวันหยุดในปฏิทิน
- บันทึกซ้อนกับรายการเดิมของครูคนเดียวกันไม่ได้
- ถ้าครูคนนั้นถูกจัดเป็นผู้สอนแทนในช่วงนั้นอยู่ ระบบไม่บันทึก และบอกให้ยกเลิกการสอนแทนก่อน
- ยกเลิกการลา → การสอนแทนที่เกี่ยวข้องถูกยกเลิกด้วย (บันทึก Log)
- หมายเหตุการลาเห็นเฉพาะ Admin หน้าสาธารณะแสดงแค่ชื่อ ประเภท และช่วงเวลา

**จัดสอนแทน** — ระบบเสนอ Admin ยืนยัน ไม่มีการมอบหมายอัตโนมัติ
1. `admin.pendingSubs` — รายการคาบที่รอจัดสอนแทนของวันที่
2. `admin.suggestSub` — รายชื่อครูที่สอนแทนได้ เช่น "นางสุภาพร พิลึก — ว่าง / สอนแทน 0 ครั้ง / วันนี้สอน 2 คาบ" พร้อมรายชื่อครูที่ไม่ผ่านและเหตุผล (สอน ป.1 / ไม่อยู่ (อบรม) / ไม่ว่างประจำ ฯลฯ)
3. `admin.confirmSub` — Admin เลือกและยืนยัน ระบบตรวจซ้ำก่อนบันทึก ถ้าครูไม่ว่างหรือทำให้ชนจะไม่บันทึก
4. `admin.cancelSub` — ยกเลิกพร้อมเหตุผล

เงื่อนไขบังคับ: ว่างคาบนั้น · ไม่สอน/ไม่ประกบห้องอื่น · ไม่ติดกิจกรรมรวม · ไม่ลา/อบรม/ราชการ/ภารกิจ · ไม่ติดเวลาไม่ว่างประจำ · สถานะใช้งาน · ประเภทครูตามค่า `substitute_teacher_types` (ค่าเริ่มต้น: ครูประจำเท่านั้น — Teacher, ครูจีน, พระธนพล และครูแดร์จึงไม่ถูกเสนอ)

ลำดับการเสนอ (เฉพาะครูที่ผ่านเงื่อนไขบังคับ): ครูประกบของคาบนั้น (กรณี Teacher หรือพระธนพลไม่อยู่) → ครูที่สอนวิชานั้นได้ → ครูที่สอนแทนน้อยครั้งกว่าในภาคเรียนนี้ → ครูที่วันนั้นสอนน้อยคาบกว่า

ค่าตั้งต้นที่ใช้จนกว่า Admin จะเปลี่ยน:
- Teacher หรือพระธนพลไม่อยู่ → ระบบเสนอครูประกบของคาบนั้นเป็นอันดับแรก แต่ไม่บังคับ ถ้าครูประกบรับสอน คาบนั้นจะไม่มีผู้ประกบ
- ครูในกิจกรรมรวม (ชุมนุม ลูกเสือ/ยุวกาชาด) ไม่อยู่ → แสดงชื่อในตารางรายวัน แต่ไม่ต้องจัดผู้สอนแทน

**รายงานภาระสอนแทน** (`public.subReport`): ครูแต่ละคนสอนแทนกี่ครั้ง วันที่ใด แทนใคร ชั้นใด วิชาใด — ครูทุกคนดูได้ — **อย่าแก้แผ่น "ตารางเรียน_Master" โดยตรง** เพราะจะข้ามการตรวจ

## การแก้ไขข้อมูล

- แก้ใน Google Sheets ได้โดยตรง **ห้ามแก้แถวที่ 1–2** (หัวตาราง) ระบบจะแจ้งเตือนถ้าคอลัมน์ถูกย้าย
- ใช้ dropdown ตามที่กำหนด วันที่ใช้รูปแบบ `2026-11-18` เวลาใช้ `08:30`
- วัน: 1 = จันทร์ … 5 = ศุกร์ · ช่อง "วันที่จัดได้/คาบที่จัดได้" ใช้รูปแบบ `1-3` หรือ `1,3,5` (ว่าง = ไม่จำกัด)
- ครู/วิชา/ชั้น/ภาคเรียน **ห้ามลบแถว** ให้เปลี่ยนสถานะเป็น "ไม่ใช้งาน" เพื่อไม่ให้ข้อมูลย้อนหลังเสีย
- การแก้ผ่านหน้า Admin (Phase 10) ถูกบันทึกใน Log อัตโนมัติ ส่วนการแก้ใน Sheets โดยตรงไม่ถูกบันทึกใน Log — ดูย้อนหลังได้จาก **ไฟล์ → ประวัติเวอร์ชัน**

## การสำรองข้อมูล (Backup)

1. **สำรองอัตโนมัติ:** เมนู **เปิดการสำรองข้อมูลอัตโนมัติรายวัน** → ระบบคัดลอกทั้งไฟล์ทุกวันเวลาประมาณ 18:00 น. ไปโฟลเดอร์ "สำรองข้อมูล ระบบตารางสอน" ใน Google Drive และเก็บ 30 ฉบับล่าสุด (เปลี่ยนจำนวนได้ที่ค่า `backup_keep`)
2. **สำรองทันที:** เมนู **สำรองข้อมูลตอนนี้** — ควรกดก่อนเผยแพร่ตาราง ก่อนสร้างภาคเรียนใหม่ และก่อนแก้ข้อมูลจำนวนมาก
3. **ประวัติเวอร์ชันของ Google Sheets:** ไฟล์ → ประวัติเวอร์ชัน → ดูประวัติเวอร์ชัน ใช้ย้อนกลับได้ทั้งไฟล์
4. **กู้คืน:** เปิดไฟล์สำรองที่ต้องการ → ไฟล์ → ทำสำเนา หรือคัดลอกแผ่นงานที่ต้องการกลับไปไฟล์หลัก (ทำเมื่อไม่มีผู้ใช้แก้ไขอยู่)

## ความปลอดภัย

- ครูทั่วไปเปิด Web App ได้โดยไม่ Login แต่ไม่เห็นไฟล์ Sheets เพราะ Web App ทำงานในสิทธิ์เจ้าของไฟล์
